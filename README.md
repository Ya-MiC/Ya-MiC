## 🎨 品牌與設計系統（溫潤設計系統 v3.1）

所有品牌系倉庫應統一消費以下設計 token，禁止散落 magic color：

**雲箋【鎖定】**（淺色主題預設）
- `--c-cloud-paper: #F8F6EF` 暖紙白
- `--c-cloud-sky: #B9DDF1` 淺天空藍
- `--c-cloud-pink: #F4DDE7` 荷花粉
- `--c-cloud-violet: #CDBFE0` 淡紫

**陶土【鎖定】**（可選分區）
- `--c-earth-oat: #E8E3CC` 燕麥米
- `--c-earth-sage: #b7c8a8` 鼠尾草綠
- `--c-earth-linen: #CBBF9E` 亞麻金
- `--c-earth-cocoa: #A38E7A` 可可棕

**中性結構層【鎖定】**
- `--ink-1: #3D3833` 正文墨色
- `--ink-2: #6E675E` 次要文字
- `--ink-3: #9C948A` 僅佔位/禁用，不作閱讀

**硬性規則**
- ✅ 四色一套，雲箋／陶土各四色封頂；中性不計入四色
- ✅ 不在 #A38E7A 可可棕上寫正文
- ✅ 一個表面只用一個色系；兩區域需用中性分隔，不混色
- ✅ 熱區 ≥48px
- ❌ #75589D 深藤紫為「提案·待確認」，不得當正式品牌色
